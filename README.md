# Cosmic Content Creator

I want to make an AI that creates posts for an Instagram account. The AI finds astronomy news articles (or takes in a pasted article link/text) and generates an engaging title, a caption summary with hashtags formatted for Instagram, and a matching visual image.

This project was built with [Lovable](https://lovable.dev).
